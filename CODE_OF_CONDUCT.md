# Code of conduct

hatchrun follows the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good intent, keep discussion on the work,
and do not harass anyone. Maintainers may remove comments, commits or
contributors that break these rules.

Report unacceptable behaviour privately to the maintainers by opening a
private security advisory on any hatchrun repository and marking it as a
conduct report.
